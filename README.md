## Featured Projects

### [TgMusicBot](https://github.com/AshokShau/TgMusicBot)
Telegram Group Calls music streaming bot built in Go utilizing `gotdbot` and `NTgcalls`. Supports streaming audio/video from YouTube, Spotify, Apple Music, and raw M3U8 streams into Telegram voice chats with low latency and minimal resource overhead.

### [ExonRobot](https://github.com/AshokShau/ExonRobot)
A feature-rich Telegram group management bot written in Python using `python-telegram-bot`. Built for high scale to handle group moderation, automated administrative workflows, and user engagement across communities.

### [telegram-web-player](https://github.com/AshokShau/telegram-web-player)
Modern, high-performance web music player integrated with Telegram. Features real-time synchronized playback, WebRTC voice chat, live room chat, personal playlists, and automated recommendations across multi-platform streaming sources.

### [coolify-telegram-bot](https://github.com/AshokShau/coolify-telegram-bot)
Go-based Telegram bot for managing self-hosted Coolify instances. Enables container listing, service deployments, live log streaming, and container restarts directly via interactive inline menus.

### [gotdbot](https://github.com/AshokShau/gotdbot)
An autogenerated, performant Go wrapper for `tdlib/td` (Telegram Database Library), making native Telegram client development in Go straightforward and efficient.

### [py-yt-search](https://github.com/AshokShau/py-yt-search)
Lightweight Python library to search YouTube videos, channels, and playlists, extract detailed metadata, and fetch query auto-suggestions without requiring a official YouTube Data API key.
